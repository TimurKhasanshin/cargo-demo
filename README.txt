Демо PWA «Страхование грузов» (1C-MSSOFT.RU)

Как показать клиенту на телефоне:
1. Загрузите содержимое папки на любой HTTPS-хостинг (например, поддомен demo.1c-mssoft.ru, GitHub Pages, Netlify, Yandex Object Storage).
2. Откройте ссылку на телефоне.
   iPhone (Safari): «Поделиться» → «На экран Домой».
   Android (Chrome): меню → «Установить приложение».
3. Приложение откроется на весь экран, без адресной строки, и будет работать офлайн.

Файлы:
index.html            — приложение целиком (логотип встроен)
manifest.webmanifest  — название, цвета, иконки
sw.js                 — офлайн-кэш
icons/                — иконки приложения

Все данные в демо вымышленные, в страховую ничего не отправляется.
